# Performance

Performance should be evaluated through results, quality, behavior, and development.

## 1. Results

Evaluate whether agreed objectives were achieved.

## 2. Quality

Consider:

- Accuracy.
- Reliability.
- Completeness.
- Customer impact.
- Maintainability.

## 3. Execution

Consider:

- Reliability.
- Ownership.
- Communication.
- Ability to solve problems.
- Ability to work independently.

## 4. Development

Performance management should identify:

- Strengths.
- Weaknesses.
- Skill gaps.
- Development opportunities.

## 5. Feedback

Feedback should be:

- Specific.
- Timely.
- Evidence-based.
- Actionable.

Criticize behavior or results, not personal worth.

## 6. Performance problems

When performance is below expectations:

1. Identify the gap.
2. Determine the cause.
3. Clarify expectations.
4. Provide support when appropriate.
5. Set a follow-up point.
6. Evaluate improvement.

## 7. Recognition

Strong performance should be recognized when appropriate.

Recognition should reinforce behaviors and results that benefit the company.
