# Metrics

Metrics exist to improve decisions and reveal whether the company is achieving its objectives.

## 1. Start with the objective

Do not choose metrics first.

First define what success means, then identify measurements that provide useful evidence.

## 2. Outcome metrics

Prefer metrics that measure actual results.

Examples include:

- Revenue.
- Profit.
- Conversion.
- Retention.
- Customer satisfaction.
- Delivery time.
- Error rate.

The appropriate metric depends on the objective.

## 3. Leading and lagging indicators

Leading indicators provide signals about future outcomes.

Lagging indicators measure results that have already occurred.

Use both when useful.

## 4. Avoid vanity metrics

A metric is not valuable merely because it is large or easy to track.

Ask:

**Does this metric help us make a better decision?**

## 5. Targets

Important metrics should have:

- Current value.
- Target.
- Deadline.
- Responsible owner.

## 6. Review

When a metric changes significantly, investigate why.

Do not assume correlation means causation.

## 7. Metrics should drive action

If a metric cannot influence a decision or action, reconsider whether it deserves attention.
